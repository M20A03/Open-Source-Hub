## 🚀 Overview

Open-Source-Hub is a collaborative engineering repository demonstrating clean code architecture, type-safe algorithms, automated CI workflows, and community best practices.

### 📦 Algorithms Library
* **Search Algorithms:** Iterative Binary Search ($O(\log n)$), Sequential Linear Search ($O(n)$)
* **Graph Traversal:** Breadth-First Search (BFS), Depth-First Search (DFS)
* **Testing:** Python `unittest` suite executed automatically via GitHub Actions CI

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/mayankrajdhn5-prog/Open-Source-Hub.git

# Run tests
python3 -m unittest discover -s tests
```
